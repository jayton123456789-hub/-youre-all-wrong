# Presentation Direction

Status: active art-direction guide for the private alpha.

## North star

The television view is a directed comedy broadcast, not a web dashboard. Each
question should briefly become its own poster while the surrounding show keeps
only the minimum permanent chrome needed for orientation.

Our original visual language is **pirate broadcast meets torn editorial print**:

- Dark full-canvas fields split by saturated cyan, magenta, acid, and orange
- Condensed kinetic headlines with crisp body copy
- Stamped verdicts, damage ledgers, torn edges, scan lines, and imperfect alignment
- A narrow live-score rail during questions
- Large theatrical reveals that clear away most interface chrome
- Simple, stable, color-matched answer controls on phones

## Presentation sequence

The long-term sequencer should expose explicit beats:

```text
category bumper
→ prompt narration
→ choices enter
→ answering opens
→ answers lock
→ verdict lands
→ host reaction
→ score ticks
→ transition
```

The 20-second countdown begins when the complete answer board appears and the
host starts reading answer one. Buttons are live at that same moment. The first
accepted lock interrupts any remaining answer narration without restarting or
extending the clock. All host speech is pre-cooked; live TTS never runs inside
this sequence.

## Question art direction

Showpacks will eventually choose from original authored layout families rather
than making every question use one composition:

- `editorial_rows` — staggered horizontal answer strips
- `split_field` — question and choices divide the canvas
- `giant_keyword` — one typographic or illustrated premise dominates
- `orbit` — choices move around a central subject
- `classification` — two destinations with clear spatial sorting

Every family must preserve a consistent A–D reading order and spoiler-safe
phone projection.

## Originality boundary

Research into earlier hosted trivia games is used only for broad lessons:
readability, brisk sequencing, sparse permanent chrome, varied bumpers, and
host-led pacing. Do not copy another game's logo, characters, host likeness,
fonts, question artwork, music, sound cues, named mechanics, category bumpers,
score rail, or exact color/layout combinations.
