# Original Host V1

This is an original synthetic host identity created from a written character
direction. It is not a recording of, or an attempt to imitate, a recognizable
performer.

`reference.wav` is the owner-approved, immutable Qwen3-TTS conditioning
reference for this voice version. It is byte-identical to audition candidate
`qwen-host-02`; do not normalize, trim, stretch, pitch-shift, or otherwise
alter it.

`profile.json` is the runtime contract, `approval.json` is the fail-closed
human approval gate, and `provenance.json` records the pinned casting and
rendering models, seed, direction, QA evidence, and approval.

Changing the reference, model, or voice ID intentionally invalidates the
content-addressed speech cache and forces the episode to be cooked again.
